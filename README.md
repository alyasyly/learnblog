# وبلاگ یادگیری (Django)

یک وبلاگ ساده و مدرن با جنگو برای نوشتن چیزهایی که یاد می‌گیری، همراه با یک **استودیو نوشتن** اختصاصی.

## راه‌اندازی

```bash
cd learnblog
python -m venv .venv
source .venv/bin/activate        # ویندوز: .venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py createsuperuser
python manage.py seed_demo       # اختیاری: چند نوشته‌ی نمونه
python manage.py runserver
```

- سایت: http://127.0.0.1:8000/
- **استودیو نوشتن: http://127.0.0.1:8000/studio/** (با همان کاربری که با `createsuperuser` ساختی وارد شو)
- ادمین پیش‌فرض جنگو: http://127.0.0.1:8000/admin/ (برای کارهای پیشرفته؛ لازم نیست)

فایل مایگریشن (`blog/migrations/0001_initial.py`) همراه پروژه است؛ فقط بعد از تغییر در `models.py` باید `python manage.py makemigrations` را اجرا کنی.

## رزومه و آیکن GitHub

- نام پیش‌فرض سایت `alyasyly blog` است. برای عوض کردنش `SITE_NAME` را تنظیم کن.
- **آیکن GitHub** در منوی بالا، زیر جستجوی صفحه‌ی اصلی و پایین سایت نمایش داده می‌شود، ولی فقط وقتی آدرس پروفایلت را بدهی:
  ```bash
  export GITHUB_URL="https://github.com/USERNAME"
  ```
  روی PythonAnywhere این خط را در فایل WSGI کنار بقیه‌ی `os.environ[...]` اضافه کن: `os.environ["GITHUB_URL"] = "https://github.com/USERNAME"`
- **رزومه** در `/resume/` است و از صفحه‌ی اصلی و پایین سایت لینک دارد. محتوایش را در فایل `blog/resume_data.py` پر کن (نمونه‌ی هر بخش داخل خود فایل است). بخش‌های خالی نمایش داده نمی‌شوند و دکمه‌ی «چاپ / ذخیره‌ی PDF» هم دارد.

## حساب کاربری و دیدگاه‌ها

هر کسی می‌تواند در `/accounts/signup/` حساب بسازد (فقط نام کاربری و گذرواژه؛ ایمیل نمی‌گیریم) و زیر نوشته‌ها دیدگاه بگذارد. بازدیدکننده‌ی بدون حساب فقط می‌خواند.

- حساب‌های تازه **معمولی** هستند و به استودیو یا ادمین راه ندارند. فقط خودت می‌توانی از `/admin/` به کسی «staff» بدهی.
- دیدگاه‌ها **متن ساده**‌اند؛ HTML و لینک اجرا نمی‌شود. هر کاربر دیدگاه خودش را می‌تواند حذف کند.
- **مدیریت دیدگاه‌ها**: `/studio/comments/` (پنهان کردن، نمایش، حذف) و همچنین `/admin/`.
- **مزاحم**: در `/admin/` کاربر را باز کن و «فعال» را بردار؛ دیگر نمی‌تواند وارد شود.
- **ضد اسپم**: فیلد مخفی برای ربات‌ها، فاصله‌ی ۲۰ ثانیه بین دو دیدگاه هر کاربر، رد دیدگاه دقیقاً تکراری، و حداکثر ۵ ثبت‌نام در ساعت برای هر IP (تنظیم در `settings.py`).
- **تأیید قبل از نمایش**: با `export COMMENTS_AUTO_APPROVE=0` هر دیدگاه تازه تا وقتی تأییدش نکنی فقط برای نویسنده‌اش دیده می‌شود. دیدگاه‌های خودت همیشه فوراً نمایش داده می‌شوند.
- **فراموشی گذرواژه** نداریم، چون ایمیل نمی‌گیریم. اگر کاربری گذرواژه‌اش را گم کرد، از `/admin/` برایش گذرواژه‌ی تازه بگذار.
- پشت پروکسی (مثل Nginx) آدرس IP همه یکسان دیده می‌شود و محدودیت ثبت‌نام روی همه با هم اعمال می‌شود؛ در آن حالت `SIGNUPS_PER_IP_PER_HOUR` را بالاتر ببر یا پروکسی را درست تنظیم کن.

بعد از به‌روزرسانی، یک بار `python manage.py migrate` را اجرا کن (مایگریشن `0002_comment` جدول دیدگاه‌ها را می‌سازد).

## استودیو نوشتن (`/studio/`)

پنلی جدا از ادمین جنگو، فقط برای نوشتن و مدیریت نوشته‌ها. فقط کاربران «staff» وارد می‌شوند.

**داشبورد**: خوش‌آمد، پیش‌نویس نیمه‌کاره برای ادامه‌ی نوشتن، آمار (منتشرشده، پیش‌نویس، زمان‌بندی‌شده، تعداد کلمات)، آخرین ویرایش‌ها و نمودار ریتم نوشتن در ۱۲ هفته‌ی اخیر.

**لیست نوشته‌ها**: فیلتر وضعیت، جستجو در عنوان و متن، فیلتر برچسب، صفحه‌بندی، ویرایش/دیدن/حذف.

**ادیتور**:

- سه حالت نمایش: نوشتن، کنار هم (متن + پیش‌نمایش زنده)، پیش‌نمایش؛ پیش‌نمایش دقیقاً با همان رندر Markdown سایت ساخته می‌شود
- نوار ابزار: پررنگ، کج، عنوان، فهرست، نقل‌قول، کد، بلوک کد، پیوند، جدول، خط جداکننده
- میان‌برها: `Ctrl+S` ذخیره، `Ctrl+B` پررنگ، `Ctrl+I` کج، `Ctrl+K` پیوند (روی مک `Cmd`)
- با Enter در فهرست، آیتم بعدی خودکار ساخته می‌شود؛ Enter روی آیتم خالی فهرست را تمام می‌کند
- ورودی برچسب‌ها با Enter یا ویرگول، با پیشنهاد برچسب‌های قبلی
- زمان انتشار با نمایش تاریخ شمسی؛ تاریخ آینده یعنی انتشار زمان‌بندی‌شده
- ذخیره‌ی خودکار یک نسخه‌ی موقت در مرورگر؛ اگر صفحه بسته شود یا برق برود، با بازکردن دوباره‌ی نوشته پیشنهاد بازگردانی می‌دهد
- هشدار هنگام ترک صفحه با تغییرات ذخیره‌نشده
- دکمه‌ی «انتشار» برای پیش‌نویس‌ها و «ذخیره» برای همه
- پوسته‌ی روشن/تاریک و نمای موبایل

**برچسب‌ها**: فهرست برچسب‌ها با تعداد نوشته و حذف برچسب‌های بی‌استفاده.

## امکانات وبلاگ

- نوشتن پست با **Markdown** (کد رنگی، جدول، فهرست مطالب خودکار، دکمه‌ی کپی روی کدها)
- طراحی **راست‌چین فارسی** با فونت وزیرمتن، حالت **روشن/تاریک**، واکنش‌گرا
- **تاریخ شمسی** و ارقام فارسی (بدون نیاز به پکیج اضافه)
- برچسب‌ها، جستجو، صفحه‌بندی، نوشته‌های مرتبط، قبلی/بعدی
- پیش‌نویس، انتشار و انتشار زمان‌بندی‌شده؛ مدیر سایت پیش‌نویس‌ها را در سایت هم می‌بیند
- فید **RSS** در `/feed/`
- فونت‌ها (وزیرمتن و JetBrains Mono، مجوز OFL) داخل پروژه‌اند؛ چیزی از Google Fonts یا CDN لود نمی‌شود

## نوشتن با Markdown

````markdown
## عنوان بخش

متن **پررنگ**، `کد درون‌خطی` و [لینک](https://example.com).

```python
print("سلام")
```
````

عنوان‌های `##` و `###` خودکار وارد «فهرست مطالب» می‌شوند.

## شخصی‌سازی

نام و توضیح سایت از متغیرهای محیطی خوانده می‌شود (یا مستقیم در `config/settings.py` عوض کن):

```bash
export SITE_NAME="یادداشت‌های علی"
export SITE_TAGLINE="چیزهایی که یاد می‌گیرم"
export AUTHOR_NAME="علی"
```

- رنگ‌های سایت: بالای `blog/static/blog/css/style.css`
- رنگ‌های استودیو: بالای `studio/static/studio/css/studio.css` (`--saffron`، `--rail-bg` و ...)
- تعداد نوشته در هر صفحه‌ی سایت: `POSTS_PER_PAGE` در `settings.py`

## تست

```bash
python manage.py test
```

## انتشار روی سرور

```bash
export DJANGO_DEBUG=0
export DJANGO_SECRET_KEY="یک-رشته-طولانی-و-تصادفی"
export DJANGO_ALLOWED_HOSTS="example.com"
python manage.py collectstatic
python manage.py check --deploy
```

برای سرو فایل‌های استاتیک پیشنهاد می‌شود از [WhiteNoise](https://whitenoise.readthedocs.io/) استفاده کنی و برنامه را با `gunicorn config.wsgi` اجرا کنی. اگر پشت HTTPS هستی، `SESSION_COOKIE_SECURE` و `CSRF_COOKIE_SECURE` را هم `True` کن.

```
│   ├── admin.py            # ادمین پیش‌فرض جنگو

│   ├── jalali.py           # تاریخ شمسی

│   ├── templates/
│   └── static/blog/        # CSS، JS و فونت‌ها

    ├── views.py            # داشبورد، لیست، ادیتور، پیش‌نمایش
    ├── forms.py
    ├── tests.py
    ├── templates/studio/
    └── static/studio/      # studio.css، studio.js، editor.js
```
